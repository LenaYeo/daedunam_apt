# 01 2026-11-28 요구사항

## 상담 신청 화면 — 유/무료 분리

### 레이아웃
좌: 무료 상담 (간단 설문 → 단지 1~2개 추천)
우: 유료 상담 (티어 선택 → 공통 + 티어별 설문)

### 무료 상담 항목
1. 이메일 주소 (필수)
2. 선호 지역 (필수) — 단지 추천 근거
3. 가용 예산

### 유료 상담 티어
1. **기본 상담** — 금액대별 제제 추천 + 텔레그램방 입장권 + 질의응답(텔방)
2. **단지 추천** — 단지 추천 (매물 3개) + 텔방입장권 + 질의응답
3. **풀케어** — 2:1 채팅방 초대 + 단지추천 + 텔방입장권 + 가계부 + 재무상담

### 유료 설문 구조
- 공통: 이메일, 성별, 거주 지역
- 기본 상담 추가: 희망 금액대
- 단지 추천 추가: 희망 지역 1·2순위, 희망 평형
- 풀케어 추가: 월 소득, 자녀 유무, 상세 상담 내용
